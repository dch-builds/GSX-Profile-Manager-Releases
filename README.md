# GSX Profile Manager — Releases

Manage your GSX Pro airport profiles for Microsoft Flight Simulator: enable, disable, repair and install profiles, scan your Community folder, and find published profiles on flightsim.to.

## Download

Get **`GSXProfileManager-win-Setup.exe`** from the [latest release](https://github.com/dch-builds/GSX-Profile-Manager-Releases/releases/latest) and run it. No administrator rights needed.

- Requires Windows 10 or 11 (64-bit). Everything else is included.
- The app updates itself: when a new version is ready, a **Restart to update** button appears in the title bar.
- Prefer not to install? Use **`GSXProfileManager-win-Portable.zip`** instead.

Upgrading from version 1.x? The installer picks up your settings and removes the old version. Your GSX profiles are not touched.

This repository only hosts the installers and update packages.
